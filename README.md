# Follow the Drop

An interactive water cycle experience I made for my AP Environmental Science project. It follows a single drop of water through the cycle - evaporation, condensation, precipitation, runoff, infiltration, and back to the top - as one continuous illustrated world, narrated in my own voice.

## Running it

Open index.html in any browser, or visit the live site. Press "Start the journey" and it plays on its own; each scene's narration finishes before it moves to the next.

## How it is built

Plain HTML, CSS, and JavaScript, no frameworks. The scenery is inline SVG, the motion uses CSS and a canvas layer, and the audio folder holds the voice-over clips.
